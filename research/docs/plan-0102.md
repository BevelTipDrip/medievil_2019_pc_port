## The port's 01.00-only sites, mapped

Method (scratchpad `find_0102.py`, Capstone): each 01.00 site's instructions with rel branch targets and RIP
displacements masked, searched in the 01.02 code for one match; data through an instruction that references it.
Cvars (`cvars_0102.py` and the final pass): the UTF-16 name, the `lea rsi, [name]` that registers it, the object
from the `mov [rip+X], rax` after the constructor call (X = object + 8) or `lea rbx, [object]` + `mov [rbx+8], rax`;
the same rule reproduces all 18 01.00 objects in the table. Checked by compiling `src/hzb_hook.h` /
`src/level_hook.h` against both images (scratchpad `hooks_check.c`: both builds recognised).
